# Terms of Use – Actual Budget

**Last updated: November 14, 2026**

## 1. Purpose

This Actual Budget instance is privately operated and self-hosted for personal, non-commercial financial management.

It is not offered as a public financial service.

## 2. Authorized Use

The application is intended exclusively for the operator's personal use.

Access is limited to authorized users. Public registration and third-party account management are not provided.

## 3. Financial Information

The application is used to track personal bank accounts, transactions, income, expenses, budgets, assets, and liabilities.

All financial information is used for personal financial management purposes only.

## 4. Banking Integration

The application may connect to financial institutions through Enable Banking.

Bank account access requires authorization from the account holder and is subject to the applicable terms of Enable Banking and the financial institution.

## 5. Data Security

The application is hosted on a privately managed ZimaOS server.

Remote access is restricted through Tailscale. The operator is responsible for maintaining the security of the server and access credentials.

## 6. No Financial Services

This application does not provide banking, payment processing, investment advice, or other regulated financial services to third parties.

## 7. Changes

These terms may be updated to reflect changes in the application's configuration or intended use.
